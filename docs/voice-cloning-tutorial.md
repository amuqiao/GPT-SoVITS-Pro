# 声音克隆端到端教程：用韩立的声音说你的话

本文用一个贯穿始终的案例——**克隆《凡人修仙传》主角韩立的声音，让韩立念出你自己写的台词**——带你走完整条声音克隆流程。所有步骤都落到这个具体目标上，不是抽象演示。

## 文档职责

- 负责：以韩立为例，完整走通两条克隆路径——先零样本速成体验，再少样本微调做出真正像的音色，含素材来源、每步界面操作、产物路径、参数建议与排查。
- 不负责：安装与首次跑通（见 [快速上手](quickstart.md)）；模型原理与代码定位（见 [项目讲解](architecture.md)）。
- 适用读者：已按 [快速上手](quickstart.md) 装好环境、能启动 WebUI 的用户。
- 前置条件：本文默认你已完成安装、下载好底模、能打开总控 WebUI（端口 9874）。没做的先回 [快速上手](quickstart.md)。

## 先建立心智模型：两条路 + 一个不变的事实

克隆韩立有两条路，深度和效果不同，本文按顺序都走一遍：

```text
Part 1 · 零样本速成 ── 给几段韩立音频，不训练，直接出声
   耗时：约 10 分钟      效果：音色中等相似，够快速验证
   代价：只需 1 段 3~10 秒干净韩立语音

Part 2 · 少样本微调 ── 用一批韩立音频训练出「韩立模型」
   耗时：数据准备+训练，约 1~数小时      效果：音色最像、发音最稳
   代价：需要几分钟~半小时的韩立干声，并走完数据准备与训练
```

有一个**贯穿两条路的关键事实**必须先记住，否则会在推理时困惑：

> **无论零样本还是微调，最终合成时都要提供一段韩立的"参考音频 + 它对应的文本"。**

原因在于系统把"内容"和"音色"分成两条通道（详见 [项目讲解](architecture.md#一核心心智模型两个解耦的模型--一座桥)）：

```text
你写的台词 ──> 内容通道（决定"说什么"）──┐
                                          ├─> 韩立念你的台词
韩立参考音频 ──> 音色通道（决定"谁在说"）──┘
```

微调只是把"韩立"这个音色训练进模型、让它更稳更像；推理那一刻，音色通道仍然靠你当场给的那段参考音频来锚定。所以参考音频从头到尾都需要。

## 素材准备：去哪找韩立的声音

先解决"素材从哪来"，这是整个流程的起点。

- **来源**：《凡人修仙传》有声书（如各平台的播讲版）、动画番剧里韩立的台词片段。
- **合规提示**：仅用于个人学习 / 研究，注意素材的版权与配音演员权益，不要用于商用或伪造、误导用途。
- **质量要求（比数量更重要）**：
  - 必须是**干声**——只有韩立说话，没有背景音乐、音效、其他角色混入。带 BGM 的素材要先用 UVR5 剥离（Part 2 第 0 步会讲）。
  - 采样清晰、无明显噪声、语气自然。
- **数量**：
  - 零样本：**1 段 3~10 秒**即可。
  - 微调：建议**几分钟到约 30 分钟**的干声。太少音色不稳，太多收益递减、训练变慢。

---

# Part 1 · 零样本速成（约 10 分钟）

目标：用 1 段韩立音频，不训练，立刻让韩立念一句你的话。这一步验证"素材可用 + 环境正常"，也是最快的成就感来源。

## 步骤

1. 准备 1 段 **3~10 秒**的韩立干声（如韩立说"此事我自有分寸"），并抄下这段话的文字。
2. 启动并进入推理 WebUI：总控 WebUI → `1-GPT-SoVITS-TTS` → `1C-推理`，开启后页面在端口 **9872**。
3. 在推理页按顺序填：

```text
GPT 权重     选底模（默认 v2Pro 底模即可）
SoVITS 权重   选底模（默认 v2Pro 底模即可）
参考音频      上传那段 3~10 秒韩立干声   ← 音色来自这里
参考文本      抄下的那句韩立原话 + 语言选"中文"
目标文本      你想让韩立说的话 + 语言选"中文"
```

4. 点击合成，几秒后试听。听到韩立的音色念出你的台词，Part 1 完成。

## 这一步的效果与局限

零样本靠底模的泛化能力"临时模仿"，**音色会有点像但不够稳**：换一句长台词、遇到生僻词，可能音色漂移或发音不稳。想要真正稳定像韩立，进入 Part 2。

---

# Part 2 · 少样本微调（做出"韩立模型"）

目标：用一批韩立音频，训练出专属的 GPT 权重 + SoVITS 权重，让韩立音色又像又稳。

## 整体流程一图

微调分三段：**造数据 → 训练 → 推理**。产物统一落在 `logs/<实验名>/`，训练出的成品权重落在 `GPT_weights_v2Pro/` 和 `SoVITS_weights_v2Pro/`。

```text
[韩立原始音频]
  │ 0a UVR5 剥背景音(素材带BGM才需要)
  ▼
[韩立干声]
  │ 0b 切分成小片 → 0(可选)降噪 → 0c ASR自动转写 → 0d 打标校对
  ▼
[标注 .list]  每行：音频路径|hanli|zh|这段话的文字
  │
  │ 1A 训练集格式化一键三连（1Aa 文本 + 1Ab 特征 + 1Ac 语义）
  ▼
[中间产物 logs/hanli/]  2-name2text.txt / 3-bert / 4-cnhubert / 5-wav32k / 7-sv_cn / 6-name2semantic.tsv
  │
  │ 1Ba 训练 SoVITS  +  1Bb 训练 GPT
  ▼
[韩立模型]  SoVITS_weights_v2Pro/hanli_e*.pth  +  GPT_weights_v2Pro/hanli-e*.ckpt
  │
  │ 1C 推理：选上面两个新权重 + 一段韩立参考音频
  ▼
[成品：韩立念你的台词，稳定像]
```

下面逐步操作。全程在总控 WebUI（端口 9874）里进行，界面标签与本文一致。

## 第 0 步：把原始音频做成标注数据

进入 `0-前置数据集获取工具`。

### 0a 剥离背景音（素材带 BGM 才需要）

`0a-UVR5人声伴奏分离&去混响去延迟工具`。若韩立素材来自带配乐的动画/有声书，先在这里分离出纯人声。素材本就是干声可跳过。（此功能需安装时带过 `--download-uvr5`，见 [快速上手](quickstart.md#第-2-步安装)。）

### 0b 切分成小片

`0b-语音切分工具`。训练需要短句片段，把长音频切开：

```text
输入        韩立干声文件或目录
输出根目录   output/slicer_opt（默认）
关键参数     threshold=-34（静音判定音量）  min_interval=300（最短切割间隔）
```

切完在 `output/slicer_opt` 得到一堆小片 wav。

### 0（可选）降噪

若切片仍有底噪，用降噪工具，输出默认 `output/denoise_opt`。素材干净可跳过。

### 0c 自动转写（ASR）

`0c-语音识别工具`。给每个切片自动生成文字：

```text
输入目录     output/slicer_opt（或降噪后的 output/denoise_opt）
ASR 模型     默认「达摩 ASR (中文)」——克隆中文韩立选它
输出         output/asr_opt 下的 .list 标注文件
```

`.list` 每行格式为 `音频路径|说话人|语言|文本`，语言码用 `zh/ja/en/ko/yue`。韩立中文素材这里说话人可填 `hanli`、语言 `zh`。

### 0d 打标校对（强烈建议做）

`0d-语音文本校对标注工具`。ASR 会有错字、断句问题，**标注质量直接决定克隆质量**。在这里逐条听音频、改文字，把明显错的修正。

## 第 1 步：训练集格式化（1A）

进入 `1-GPT-SoVITS-TTS` → `1A-训练集格式化工具`。先填三个公共项：

```text
*实验/模型名          hanli   ← 后续产物和权重都用这个名字
*文本标注文件          第 0 步得到的 .list 路径
*训练集音频文件目录     第 0 步切分/降噪后的音频目录
GPU卡号以-分割…        单卡填 0
```

然后用 `1Aabc-训练集格式化一键三连` 一次跑完三个子步骤（也可单独跑 1Aa/1Ab/1Ac）：

```text
1Aa 文本分词与特征提取   → logs/hanli/2-name2text.txt , 3-bert/*.pt
1Ab 语音自监督特征提取   → logs/hanli/4-cnhubert/*.pt , 5-wav32k/*.wav
                        （默认 v2Pro 会自动附带说话人向量 → 7-sv_cn/*.pt）
1Ac 语义Token提取        → logs/hanli/6-name2semantic.tsv
```

> 三步有先后依赖（1Ac 依赖 1Ab 的产物），所以推荐用"一键三连"，它已按 `1Aa→1Ab→1Ac` 顺序执行。跑完到 `logs/hanli/` 确认上述产物都在。

这些产物精确对应两个模型的输入（详见 [项目讲解](architecture.md#四微调训练流水线)）：GPT 吃语义+音素，SoVITS 吃声学特征。

## 第 2 步：微调训练（1B）

进入 `1B-微调训练`。两个模型分开训，先后不限，都要训。

### 1Ba 训练 SoVITS（声学，决定音色）

`1Ba-SoVITS 训练: 模型权重文件在 SoVITS_weights/`：

```text
每张显卡的batch_size     用默认值；显存不足就调小（会自动再对半降）
总训练轮数total_epoch     用默认值（随版本给出），"不建议太高"
保存频率save_every_epoch  用默认值
GPU卡号                  0
```

点开始训练。成品权重落在 `SoVITS_weights_v2Pro/hanli_e<轮>_s<步>.pth`。

### 1Bb 训练 GPT（语义，决定发音稳定与韵律）

`1Bb-GPT 训练: 模型权重文件在 GPT_weights/`：

```text
每张显卡的batch_size     用默认值；显存不足调小
总训练轮数total_epoch     默认 15
保存频率save_every_epoch  默认 5
GPU卡号                  0
```

点开始训练。成品权重落在 `GPT_weights_v2Pro/hanli-e<轮>.ckpt`。

> 显存是主要约束。跑不动就先降 `batch_size`；轮数保持默认即可，过高反而过拟合、音色发闷。

## 第 3 步：用韩立模型推理（1C）

进入 `1C-推理`，开启推理 WebUI（端口 9872），这次**选你训出来的权重**：

```text
GPT 权重      选 GPT_weights_v2Pro/hanli-e*.ckpt   ← 不是底模
SoVITS 权重    选 SoVITS_weights_v2Pro/hanli_e*.pth ← 不是底模
参考音频      一段 3~10 秒干净韩立干声（仍然需要，见开头心智模型）
参考文本      这段参考音频对应的文字 + 中文
目标文本      你要韩立说的台词 + 中文
```

> 权重列表没刷新出新模型时，点界面上的刷新按钮重新扫描 `*_weights_*` 目录。

点击合成。这一版是"韩立模型 + 韩立参考音频"，音色比 Part 1 明显更稳更像。至此，"用韩立的声音说你的话"的完整流程走通。

## 效果调优与常见问题

- **音色不够像** → 素材偏少或偏杂：增加干净韩立干声、做好 0d 打标校对，通常比加训练轮数更有效。
- **发音不稳 / 漏字重复** → GPT 训练不足或素材标注差：先保证标注准确，再适度加 GPT 轮数。
- **音色发闷 / 机械** → 训练轮数过高过拟合：换更早一轮的权重（`e` 值更小的那个 `.pth`/`.ckpt`）。
- **显存不足训不动** → 调小 `batch_size`；仍不行用更小 batch 或 CPU（慢）。
- **权重选不到新模型** → 点刷新；确认落在 `GPT_weights_v2Pro/` 与 `SoVITS_weights_v2Pro/`（版本目录要和推理选的版本一致）。
- **中文注音报错** → 缺 `G2PWModel`，见 [快速上手 · 手动补底模](quickstart.md#第-3-步可选手动补底模)。
